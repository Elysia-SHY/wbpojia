## v2.3.0

### 合并

并入 [#2](https://github.com/Elysia-SHY/wbpojia/pull/2)（作者 danlingdan），针对 #1 的写入受阻处理：

- 按目录预检后再写，受阻时汇总成一段「写入受阻」，不再是 18 个文件各刷一行。
- 权限提示只出现一次；已提权仍被拒时提示指向目录 ACL、占用与安全软件，而不是重复建议提权。
- 备份失败即跳过该文件，不再无备份覆盖客户端原文件。
- 全部写入失败时不再打印「提示词靶点全部已是最新」与自证口令，退出码保持 1。
- 面板显示安装目录写入状态：页面里提权没有用，提示的是进程侧怎么做。

### 新增

- 自动提权：安装目录位于 `%ProgramFiles%` 时，`apply` / `onekey` 通过 UAC 以 `runas` 重跑原命令，等待管理员进程结束并透传其退出码。面板点击操作同样处理，并回报退出码。
- `--no-elevate`：关闭自动提权，只以当前权限执行，适合只想处理用户目录或被组策略限制 UAC 的场景。

### 修正

- 回读核对不再因写入列表为空而跳过；发现的未生效项计入错误数与退出码。
- `--restart` 仅在无错误时执行，避免写入失败还去重启客户端。

### 升级说明

直接覆盖旧版 exe 即可，`persona.md` 与 `_wb状态\` 不需要迁移。已打补丁的客户端重跑一次 `apply` 会因版本号变化全量复查一遍。
