## v2.1.0

### 新增

- `persona` 子命令，自定义系统提示词不再需要编辑文件。`persona` 查看当前人格，`persona set "..."` 设置，`persona set --file ...` 从文件读取，`persona reset` 恢复内置人格。
- 面板新增人格编辑区，含保存、保存并应用、恢复内置默认三个操作。
- JS 写入前执行 `node --check`，未通过则跳过该文件；无 node 时退化为括号配平检查。
- Scoop 清单 `docs/scoop/wbpojia.json`，以及 `docs/scoop.md`、`docs/compatibility.md`。

### 变更

- 子命令由 11 个增至 12 个。
- 闸门由 2 处增至 5 处：新增 `BashTool.needsApproval`、`isSandboxForcedByManagedPolicy`、`getDestructiveCommandWarning`。
- `status` 的 L3 段逐条列出闸门名称与状态。
- `apply --quiet` 先比对指纹，无变化时跳过全量扫描。
- Release 包名改为 `wbpojia-v2.1.0-win64.zip`。

### 修正

- 修改人格后，已打过补丁的文件不更新。原因为节省一次 386 KB 写盘而跳过了哈希不一致的文件，人格变更被一并跳过。现改为哈希不一致即重写。
- `persona reset` 将参数 "reset" 当作正文写入。

## v2.0.0

首个独立发布版本。

- 引擎重写：六层分层输出，新增 `doctor`，接管控制台代码页（修正 v1.1 的乱码）。
- 提供控制台版与无窗口面板版两个 exe。
- L2 补上漏扫的 `node_modules\@genie\agent-harness\cli\product.json`。
- L5 原删除的文件名已不存在，改为按 `<pid>-<uuid>` 命名逐份判断。
- `--ask-mode` 此前未生效：唯一靶点不含 `<content_policy>`，改动在跳过逻辑处丢失。
- `revert` 会用旧 `.pojia.bak` 覆盖客户端后续写入的记忆。
- `apply --full` 先中和文件保护再整块替换政策段，中和失效。
- `guard-install --dry-run` 恒定返回 1；两条计划任务补上 `/RL HIGHEST`。
