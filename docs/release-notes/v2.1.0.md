## 这次主要在解决「改人格还得去动文件」

v2.1 起自定义系统提示词有了正式入口，两条路任选：

| 方式 | 怎么做 |
|---|---|
| 面板（推荐） | 双击 `wbpojia-panel.exe` → 「自定义系统提示词」卡片里写完 → **保存并应用** |
| 命令行 | `wbpojia persona set "你的提示词"`、`persona set --file D:\path\persona.md`、`persona reset` |

`wbpojia persona` 不带参数会显示当前来源、字数、保存位置和**当前生效的正文**。存哪儿不用你管：写在 exe 同目录，那目录不可写（比如塞进 `Program Files`）就自动落到 `%LOCALAPPDATA%\wbpojia\persona.md`。

优先级：`--persona` 参数 > 同目录 `persona.md` > 同目录 `my-prompt.txt` > 状态目录 `persona.md` > 内置小码酱。

> 面板里点「保存并应用」会顺手打一次补丁；只点「保存」的话，下次 `apply` 生效。

## 命令闸门从 2 道扩到 5 道

原来只把 `checkBashSecurityWindows` / `checkPowerShellSecurity` 改成直接放行。逆向复核后补上真正还在拦的三处：

- **`BashTool.needsApproval`** → 首行 `return!1` —— 这是实际还会弹审批的地方，之前漏了。
- **`isSandboxForcedByManagedPolicy`** → `return false` —— 托管策略不再强制开沙箱。
- **`getDestructiveCommandWarning`** → `return null` —— 危险命令提示不再返回文案（在前两条早退之后它是死代码，补上是兜底）。

`status` / `check` 的 L3 现在会逐条列出闸门名和「已开/未开」，本机实跑是 `[已开 5/5]`。

## 改 JS 前先验语法，验不过就不写

新增安全网：注入完立刻用 `node --check` 校验整份文件，不通过就放弃这个文件、不写盘；本机没 node 就退化成括号配平检查。`doctor` 会显示用的是哪个 node。可用 `--no-verify` 跳过（不建议）。

## 自愈任务不再空转

`guard-install` 的两条计划任务还是每 30 分钟 + 登录时，但 `apply --quiet` 会先比对指纹（目标目录 mtime / 条目数 / `installed_plugins.json` 与 `product.json` 的哈希 / 引擎版本）。没变就 50 ms 退出，不再扫 692 个文件。

## 修掉一个真 bug

改了人格但补丁不更新 —— 旧的「哈希对不上就跳过」逻辑会把人格变更吞掉，只有在 `--force` 下才写。现在只要哈希对不上就重写，人格改完 `apply` 立刻生效。

## 装到别人机器上

多了 Scoop 清单：

```powershell
scoop install https://raw.githubusercontent.com/Elysia-SHY/wbpojia/main/docs/scoop/wbpojia.json
```

不用装 Python，不建 bucket，`scoop update wbpojia` 就能升级。详见 `docs/scoop.md`。
