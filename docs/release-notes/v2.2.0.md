## v2.2.0

### 新增

- 全机安装（`%ProgramFiles%`）不必再手动右键管理员运行。`apply` / `onekey` 检测到安装目录位于 Program Files 时，通过 Windows UAC 以 `runas` 重新执行原命令，等待管理员进程结束并透传退出码。面板发起操作时同样处理。
- `--no-elevate`：关闭自动提权，只以当前权限执行，适合只想处理用户目录或被组策略限制 UAC 的场景。

### 修正

- **备份失败不再继续写入**（对应 #1）。`.unlockbak` 建不出来时，原来仍会写目标文件，等于无备份覆盖客户端原文件；现在跳过该文件并计入错误。
- **失败不再按完成收尾**（对应 #1）。全部靶点写入失败时，原来仍打印「提示词靶点全部已是最新」并以 0 退出；现在汇总为「未完成」、返回 1。
- **回读核对不再被跳过**。写入列表为空时原先直接跳过核对，现在只要存在错误就执行，未生效项一并计入错误数。
- **权限提示区分是否已提权**。已以管理员运行时仍报 `Errno 13`，提示改为检查目录安全权限、所有者与安全软件拦截，而不是重复建议提权。
- Web 过滤写入的异常不再打断整个 `apply`。

### 变更

- `--restart` 与「请完全退出 WorkBuddy（含托盘）」只在无错误时出现。
- 自测新增：备份失败保护、失败退出码与文案、提权开关、UAC 调用参数与管理员进程退出码透传。

### 升级说明

直接覆盖旧版 exe 即可，`persona.md` 与 `_wb状态\` 不需要迁移。已打补丁的客户端重跑一次 `apply` 会因版本号变化全量复查一遍。
