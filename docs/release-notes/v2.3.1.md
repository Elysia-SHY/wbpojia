## v2.3.1

### 修正

- **非系统盘安装目录导致 apply 崩溃**。WorkBuddy 装在 `D:\Program Files\WorkBuddy` 这类路径时，v2.3.0 的提权判定用 `os.path.commonpath` 比较不同盘符，直接抛 `ValueError: Paths don't have the same drive`，整个 `apply` 以「内部错误」收场。现在跨盘路径按「不受系统 UAC 保护」处理，不再提权、正常写入；已补回归测试。

客户端升级后补丁被覆盖属于预期：重跑一次 `apply`（或 `onekey`）即可，v2.3.1 起非系统盘也能直接跑。
